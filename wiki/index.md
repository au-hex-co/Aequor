# Aequor Wiki

**Aequor** (working title *Merchant of Fate*) is a pirate roguelike shipbuilder and 2D naval combat game about a debt that outlives its own gods. See [[overview]] for the visual map of the whole project (Excalidraw board).

## Naming Note
`wiki/characters/` holds **in-game** character material (the protagonist as the player encounters them). `wiki/world/Characters/` holds the **lore** — the gods and mythic figures behind those in-game entities. See each folder's index for how the two relate.
